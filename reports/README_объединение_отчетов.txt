ИНСТРУКЦИЯ ПО ОБЪЕДИНЕНИЮ ОТЧЕТОВ
================================

Созданы следующие файлы:

1. объединенный_отчет_все_лабораторные.docx
   - Простой объединенный документ со всеми отчетами
   - Размер: 99,727 байт

2. объединенный_отчет_структурированный.docx  
   - Улучшенная версия с титульной страницей и структурой
   - Размер: 102,480 байт

3. оглавление_отчетов.txt
   - Текстовый файл с оглавлением всех отчетов
   - Размер: 585 байт

4. объединить_отчеты.py
   - Основной скрипт для объединения отчетов
   
5. объединить_отчеты_расширенный.py
   - Расширенный скрипт с улучшенной структурой

КАК ИСПОЛЬЗОВАТЬ:
-----------------

1. Для простого объединения:
   python объединить_отчеты.py

2. Для создания структурированного документа:
   python объединить_отчеты_расширенный.py

3. Скрипты автоматически найдут все .docx файлы в текущей папке
   и создадут объединенный документ.

ПРИМЕЧАНИЯ:
----------
- Скрипты используют библиотеку python-docx
- Текст извлекается из параграфов и таблиц
- Сохраняется исходное форматирование текста
- Между отчетами добавляются разрывы страниц
- Создаются заголовки для каждого отчета

Для дальнейшей настройки можно редактировать скрипты:
- Изменять стили текста
- Добавлять дополнительные разделы
- Настраивать поля и форматирование
- Добавлять нумерацию страниц и т.д.
